# AMRAP

App web para entrenamientos AMRAP de 20 minutos con contador de vueltas, guía visual de ejercicios y seguimiento mensual de racha.

## Funciones
- **Cronómetro de 20:00:** cuenta regresiva, barra de progreso, sonido/vibración al finalizar y control de pantalla activa.
- **Vueltas y estaciones:** contador de vueltas completadas y checklist interactivo de los 6 ejercicios del circuito.
- **Guía de ejercicios:** diagrama visual, pasos clave, errores a evitar y adaptaciones para cada movimiento.
- **Progreso y racha:** calendario mensual con racha de días entrenados, edición manual de días y carga o descarga de respaldo en JSON.

## Cómo usarlo
1. Descargá o cloná el repositorio.
2. Abrí el archivo HTML en tu navegador (o entrá al enlace de GitHub Pages si está publicado).

## Guardado de datos
El historial de entrenamientos se guarda en el navegador mediante `localStorage`. Podés usar los botones **Exportar JSON** e **Importar JSON** en la sección de Progreso para hacer copias de seguridad o mover tus datos.
