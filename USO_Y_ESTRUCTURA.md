# Uso en el Celular y Estructura del Proyecto

## Pensado para uso móvil
- La interfaz está armada con navegación inferior fija, botones amplios para el pulgar y tipografía clara para leer rápido durante el entrenamiento.
- En la pestaña **Entrenar**, el botón **Pantalla Activa** permite intentar mantener la pantalla encendida mientras corre el reloj (si el navegador soporta Screen Wake Lock).

## Estructura del proyecto
- `index.html` — Estructura principal de la aplicación web.
- `styles.css` — Estilos base, comportamiento táctil y ajustes para pantallas móviles.
- `tailwind.config.js` — Paleta monocromática y tipografía Arimo configurada en Tailwind.
- `app.js` — Lógica del cronómetro de 20:00, contador de vueltas, checklist, guías SVG y calendario mensual.
- `README.md` — Portada principal del repositorio.
- `EJERCICIOS.md` — Detalle de los 6 ejercicios del circuito.
- `PROGRESO.md` — Funcionamiento del calendario, rachas y respaldo en JSON.
- `USO_Y_ESTRUCTURA.md` — Notas de uso móvil y organización de archivos.
